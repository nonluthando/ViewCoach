# Learning Roadmaps

Roadmaps organise what a user is learning for a role, skill or interview
practice area.

## Structure

A roadmap contains ordered sections and topics. Users can track each topic
as not started, in progress or completed and can save private notes and
learning resources.

## Learning versus review

Roadmap topics represent learning. Questions represent review and interview
preparation. A topic may be connected to relevant questions, but rereading
a topic is not treated as spaced review.

## Daily learning

The planner selects unfinished topics from active roadmaps and favours
continuity with work already in progress. It limits the number of roadmaps
used in one day to reduce unnecessary context switching.

## Topic depth

More available time should create deeper learning, exercises and project
work rather than an unlimited number of new topics.
