# Finding your way around ViewCoach

ViewCoach is organised around one preparation loop: **Plan → Learn → Retain
→ Prove → Rehearse**. Every item in the sidebar belongs to one stage of that
loop.

## Sidebar sections

**Command**
- **Dashboard** — today's recommended next step, readiness stats, and a
  summary card for every stage of the loop in one place.
- **Daily Plan** — turns your available study time into an ordered list of
  preparation blocks for today.

**Build**
- **Roadmaps** — structured learning paths. Each roadmap has ordered topics
  you mark as not started, in progress, or completed.
- **Reviews** — the spaced-repetition queue for interview questions you've
  added notes to.

**Prove**
- **Interview Hub** — start and run timed mock interviews, and review past
  sessions.
- **Evidence Bag** — where real work (projects, incidents, decisions) is
  logged and turned into project explanations and behavioural stories.

**Library**
- **Resources** — the question library and saved learning resources.
- **Settings** — account details and preparation preferences (which need
  types the planner should favour).

## On mobile

Below roughly 928px wide, the sidebar becomes a hidden drawer opened with
the menu button in the top header. Four shortcuts also sit in a bottom tab
bar for one-tap access without opening the drawer: **Today** (Dashboard),
**Learn** (Roadmaps), **Prepare** (Reviews and Evidence Bag), and
**Interview** (Interview Hub).

## Getting help without leaving the app

The Help Assistant (this feature) answers questions about how ViewCoach's
features work, grounded only in ViewCoach's own documentation — it does not
read your private evidence, CV, goals, or interview history, and it will
say so rather than guess when it can't find a supported answer.
