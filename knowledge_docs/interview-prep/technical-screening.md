# Technical Screening

A junior technical screening call evaluates foundations, problem solving, and the
ability to communicate technical work clearly.

## Common formats

The screen may include verbal concept questions, a short coding problem, SQL,
debugging, API reasoning, or a discussion of a previous project. The exact mix
depends on the role.

## How to answer

Start with the direct answer, then explain the reasoning. State assumptions when a
question is ambiguous. For coding or debugging, describe the approach before writing
details, test a small example, and check edge cases.

## Junior depth

Strong fundamentals matter more than pretending to know every advanced topic. It is
acceptable to say that you have not used something in production, then connect it to
related knowledge and explain how you would learn or verify it.

## Project questions

Be ready to explain the problem, architecture, personal contribution, one important
decision, one difficult bug, testing, trade-offs, and what you would improve next.
