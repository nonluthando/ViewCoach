# Using the Help Assistant

The Help Assistant answers questions about how ViewCoach works — what a
feature does, where to find it, and what a field on a form means.

## What it can answer

Questions grounded in ViewCoach's own product documentation and its
feature forms: how the daily planner works, what an interview goal is for,
how to log evidence, what the readiness score considers, and similar
"how does this work" or "where do I find X" questions.

## What it cannot do

- It does not read a user's private data — no evidence items, goals,
  interview history, or CV are included in what it searches.
- It will not answer questions outside ViewCoach's own documentation. If no
  supporting content is found, it says so rather than guessing.
- It is not a place to get real interview coaching or an evaluation of an
  answer — that happens in the Interview Hub and Evidence Bag instead.

## How answers are grounded

Every answer is built only from retrieved ViewCoach documentation, and each
claim is expected to cite the source it came from. If the assistant cannot
find supporting material for a question, it returns an explicit
"could not verify an answer" response instead of inventing one.
