# Questions and Spaced Review

ViewCoach combines a structured interview question library with
deterministic spaced-review scheduling.

## Question types

The library supports technical, conceptual, behavioural, debugging and
repository-style questions. Questions can contain preparation notes,
intuition, approaches, complexity, mistakes and supporting evidence.

## Ready for review

A question should only enter scheduled review after it contains useful
notes. Imported or incomplete questions remain in a Needs Notes state until
they are prepared.

## Review ratings

After attempting a question, rate recall as Again, Hard, Good or Easy.
These ratings update the next due date, interval, repetition count, lapse
count and ease-related scheduling state.

## Due reviews

Due and overdue questions are time-sensitive. The planner reserves time for
them before assigning new learning and practice.

## Coherent review groups

Review sessions group related questions by topic or question type where
possible. The user should finish one coherent group before switching to an
unrelated domain.
